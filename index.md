# Privacy Policy — Tech Meets Money Upload Assistant

Last updated: 19 September 2026

## Who operates this tool

This tool is operated by Mekki [torkia], an
individual creator, as a private automation used solely to
manage the YouTube channel "Tech Meets Money"
(https://www.youtube.com/@TechMeetsMoney0).

Contact: TechMeetsMoney0@gmail.com

## What this tool does

The tool is a private workflow that prepares draft videos
and uploads them to the operator's own YouTube channel
with private visibility. All uploads are reviewed and
published manually by the operator.

## Who can use it

This tool has a single user: its operator. It is not
publicly accessible, not distributed, and not offered as
a service to any third party.

## Data collected

This tool does not collect, request, or store personal
data from any other person. It has no users other than
the operator, no accounts, no sign-up, and no database
of personal information.

## YouTube API Services

This tool uses YouTube API Services. By using it, the
operator is bound by the YouTube Terms of Service
(https://www.youtube.com/t/terms) and the Google Privacy
Policy (https://policies.google.com/privacy).

The tool accesses the operator's own YouTube account via
OAuth 2.0, using the minimum permissions required to
upload videos to that account. It does not access, read,
or store data belonging to any other YouTube user.

Authorisation tokens are stored in the operator's private
n8n Cloud workspace and are used only to upload to the
operator's own channel. The operator can revoke this
access at any time at
https://myaccount.google.com/permissions.

## Data retention

No third-party personal data is collected, so none is
retained. Video metadata generated by the tool is stored
only in the operator's own n8n workspace and YouTube
account.
